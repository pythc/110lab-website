# 0.16.1 飞书通讯录管理员

取消添加管理员前必须先登录工作台的限制。超级管理员可搜索并选择服务器当前可见的飞书通讯录成员。提交授权时绕过通讯录缓存，重新确认成员可见性、当前会话、CSRF、五分钟内身份确认、超级管理员权限和名单修订号。通讯录不可用时关闭新增入口并显示错误，不回退成少量已登录成员。

授权绑定 tenant_key + union_id，不以姓名或猜测的邮箱匹配。未登录成员保存在新增的 directory_admin_grants 表中，不伪造登录或邮箱；首次经过现有企业登录验证后，在同一事务中转入既有管理员表。登录前可按身份撤销；通知邮箱同步同时包含这些已授予身份。转让超级管理员仍要求目标完成过企业登录。

审计通过附加表保留新增授权和撤销的目标身份、姓名；旧审计记录不变。现有角色、登录方式、招新发送配置和候选人不变。本次不自动给真实成员授权，不发送测试邮件或飞书消息。

发布前备份全部 SQLite、旧 release 和网关。只替换门户 HTTP 与通知邮箱成员同步 worker，不重启考核、批改、招新发信 worker。先关闭新增管理员写入，等待在途请求，验证新 worker 再恢复。数据库变更为追加表，无删除、改写旧表。公开首页和视频字节保持不变。

回滚：恢复旧 HTTP 上游和 current 指针，保留全部业务数据。若尚未产生 directory_admin_grants 或对应审计，可恢复旧成员同步 worker；若已产生新授权，必须保留新版成员同步 worker，并关闭旧版管理员写入入口，直到修复版本上线，避免隐藏的新授权被旧同步逻辑撤销。不得恢复旧数据库覆盖新授权或候选人。
