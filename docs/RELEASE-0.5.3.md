## 回滚

`deploy/rollback.py` 为本机受限部署工具，不进入发布包；默认只读核对，`--apply` 才执行回滚。它核对新旧容器 ID、release 指针、当前共享配置 SHA 和备份 SHA；若其他项目改变共享网关，拒绝覆盖。启动旧版本并验证健康后，原 inode 写回该次发布备份的 Caddyfile，validate/reload 后停止新首页并恢复旧 release 指针。不会删除历史数据、改变 DNS 或重启考核/批改服务。

发布工具的异常分支会恢复原 upstream，并停止失败候选。公网与运行时检查不通过时使用上面的回滚；旧容器只在验收通过后停止，仍保留以便回退。

## 公网验收

核对 HTML 与发布清单 SHA、健康版本、邮箱/邮件主题、智评学堂标志、ICP备案、考核 HTTPS 入口、视频完整 SHA 与 Range/缓存、APK/下载清单、动态空态/ETag。真实浏览器确认视频播放和拖动，同一页面在 60 秒后再次请求公共动态；不向生产发布测试动态。发布/撤回导致 DOM 更新的行为沿用本地同页验收与自动化测试证据。

管理页面和写入路径在主域与 internal 都应拒绝访问，工作台和只读 MCP 保持可用。最终核对加载中的 Caddy upstream、当前 release、容器文件摘要/运行时及其它服务状态。实际时间、提交、容器、备份和验证结果保存在受忽略的 `artifacts/deployment/`，凭据不进入报告。
