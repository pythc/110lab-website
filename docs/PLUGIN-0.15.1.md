# 110lab 插件 0.15.1

修复本机飞书登录连接的重试：MCP SDK 在初始化失败后会关闭传输对象，旧代码继续复用同一个对象，后续点击登录立即失败。现在每次登录建立独立客户端和传输，仅复用私有文件中的有效身份凭据。

原 30 天有效期、主动退出撤销、PKCE、本机回调校验、并发登录锁和业务权限均不变。升级完成后再发起登录，避免关闭仍在等待授权的旧回调端口。原登录记录已失效时需要重新完成飞书授权。

验证：补充“自动恢复初始化失败后，手动重试完成 OAuth 和 iframe 交接”的回归；登录、OAuth、持久化相关 14 项测试通过。错误提示来自本机桥接，客户端日志未保留首次底层异常，不能将所有实际报错都归因于该重试缺陷。发布后仍需当前侧栏实际登录验证。

本次仅更新客户端插件，服务端维持 0.16.1；不重启生产服务，不调整账号权限或发送邮件。GitHub 安装源和个人私有插件使用同一修复，保留旧版本归档。回滚插件不能恢复已撤销的登录凭据，也不回滚服务器数据。
